# The layer of every file (tools/check_layers.py, docs/MODES.md sections 2 and 5).
# One row: <layer> <glob>. Globs are relative to the repository root, `**` = any folders, `*` = any name part.
# The LAST matching row wins. A path no row matches is core (Ядро): an unclassified new file gets the strictest rules.
#   stock-list <file>  the list of GSC files that `stock` rows cover (tools/stock_files.txt)
#   core      Ядро: both modes, same behaviour, no mode checks
#   hostplay  Кооп: only where the host plays himself (LocalLink, group move, Steam)
#   srv       Сервер: world server and map servers only
#   stock     GSC engine files (with or without our hooks): a new hook line fails (L5), an edit is an Ядро change
#   dying     hybrid code, removed in step S2 (exempt from L1/L2/L4/L6 until then); only the five files of
#             check_layers.DYING_FROZEN: a dying row that names another file is ignored
#   gate-core read by tools/check_gates.py only: the file counts as Ядро for the gate whatever its layer (critique H4)
# Classification source: temp/modes/map-engine.md 2.1 (classes SERVER, MAPSERVER, SPLIT -> srv; COOP -> hostplay;
