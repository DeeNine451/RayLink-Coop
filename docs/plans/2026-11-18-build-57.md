## 3. Общие правила для всех исполнителей

- **Один файл — один владелец.** Юнит получает задание, только когда все прежние владельцы его файлов закоммичены
  (порядок — раздел 4). Sol и Opus работают в одном рабочем дереве.
- **Хабы — у ведущей.** `tools/*` (после приёмки S1), `xrGame.vcxproj(.filters)`, `tools/build_tests.cmd`,
  `tools/test_lua.cmd`, `tools/layers.txt`, `layers_allow.txt`, `persisted_keys.txt`, `srv_entry.txt`, `tools/stand_*.ps1`,
  `check_gates.SCENARIOS`, `docs/MODES.md`, `TZ.md`, `docs/TESTERS.md` (кроме F5-DOC-2 в W8),
  `gamedata/configs/mod_system_coop_trust.ltx` (умолчание `log` покрывает новые проверки — строк не добавлять). Юнит
  пишет в отчёте, что внести.
- **Протокол — один подъём.** 32 → 33 делает A-S3W. Всё новое на проводе в этой сборке (сообщения F5-PROTO, `kMaxPlayers`
  16, поле собеседника, если понадобится — поле G6-1/G6-3) входит в 33 без второго подъёма.
- **Слои.** Ядро не спрашивает режим (L1/L2): только `coop_mode.*` / `mode()`, и только про игрока, карту или своего
  актора. «Временно через `is_host()`» нельзя — `check_layers` не пропустит. Новый серверный код — `coop_srv_*` или
  `srv/`, регистрация внутри `coop_mode.when_srv` (L9). Новых локалей в `coop_tasks` и `coop_npc_companions` нет (L7).
- **Слово клиента** — через `coop_trust`, в 57 режим `log`.
- **Тесты сначала**, красные по нужной причине. Тесты Ядра идут под наборами `hostplay`, `srv_world`, `srv_map`, `none`;
  srv-юниты — `test_srv_*`, набор кооп-тестов не меняется.
- **Движок не собирают** исполнители; живую игру владельца не трогают; стенд гоняет только ведущая, в E.
- **Отчёт:** изменённые файлы, команды и итог, по строке на режим (сделано и проверено / сделано, не проверено / не
  сделано / не нужно), пункты для тестеров по режимам, новые сохранённые ключи.
- **Ревьюеры** читают коммиты своих юнитов (`git show`), а не рабочее дерево: в W8 файлы движка переезжают.
- **Sol** — точное задание, тайм-бокс и запуск по `CLAUDE.md` §8 (`run-sol.ps1`), без git, без vault, без вложенных
  агентов; длинный юнит ведущая режет на шаги; итог перепроверяет выборочно. Часы юнитов — оценка объёма, не время Sol.
- Номера строк в заданиях — на 2026-11-18; место ищется по коду, а не по номеру.
