# Два режима: план работ

Решения владельца 2026-11-18 (`CLAUDE.md`, `TZ.md` §2): остаются Кооп и Сервер; гибрид и «сюжетные карты вместе»
убираются; из игры запускается только Кооп, Сервер — только из лаунчера; Steam только в Коопе; общий код получает имя
и правила, чтобы правка сервера не задевала кооп. Архитектура и правила — `docs/MODES.md`.

Основание: `temp/modes/map-engine.md`, `map-scripts.md`, `map-products.md`, `design-boundary-first.md` (BF),
`design-physical-split.md` (PS), `critique.md`. Принят объединённый вариант из критики (§8): одна кодовая база, три
слоя, сначала проверка границ, потом удаление гибрида, потом интерфейс.

Почему не две копии кода: около 90 % кода общее (синхронизация, инвентарь, смерть, задания). Копия — это каждый баг
чинить дважды. Разделяем слоями с жёсткой автоматической границей. Массовое переименование всего Ядра (`coop_*` →
`rl_*`, около 120 скриптов, 600 строк `#include`) из PS не берём: +8-10 дней, кооп-код ездит через переименования, для
игрока ничего (critique §0).
