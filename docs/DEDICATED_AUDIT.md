# Аудит «хост играет» для выделенного хоста (2026-11-01)

Всё найдено чтением кода: C++ 511 мест `is_host`/`kHostPeer`/`is_player`, Lua 98 файлов, ~620 мест. Живым запуском не проверялось.
Спецификация: `docs/DEDICATED_HOST.md`. Живая проверка: `docs/checks/2026-11-01-dedicated-host.md`.

Правило оценки. Выделенный хост это хост, чей игрок стоит на `fake_start`, поэтому большая часть кода уже верна: для игроков хост просто на другой карте. Ломается только то, что считает хоста **присутствующим человеком**.

## Проверено, правка не нужна

- **Автосейв:** призрак жив и не спит, `can_write` и `bad_moment` проходят.
- **Переход хоста, табло, `host_pick_movers`:** всё требует актёра в зоне перехода, призрак там не бывает.
- **Новая игра и `fake_start`:** актёр `all.spawn` стартует там, `place_ghost` для новой игры не нужен. Отчёт C++ аудита (M5) считал, что актёр на Кордоне: это не так, см. `tools/launch.ps1:78`.
- **Погода:** `[fake_start] weathers = atmosfear`, обычный уличный цикл, `surge_manager` и `psi_storm_manager` работают по расписанию.
